# 机器学习与深度学习基础

## 基本概念

- 监督学习：使用带标签数据训练模型，常见任务包括分类和回归。
- 无监督学习：在无标签数据上发现结构，如聚类、降维和异常检测。
- 强化学习：通过与环境交互获得奖励信号，学习最优策略。

## 常见算法

- 线性回归、逻辑回归
- 决策树、随机森林、支持向量机
- K-means、主成分分析（PCA）
- 神经网络、卷积神经网络（CNN）、循环神经网络（RNN）

## 实践建议

- 先明确问题类型：分类、回归、聚类或序列预测
- 选择合适特征并进行特征工程
- 使用交叉验证评估模型稳定性
- 对模型进行超参数调优并监控过拟合
